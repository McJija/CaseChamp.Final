# Сравнение версий: прежняя `models/final`, `run3` и `run4`

Прежняя — `models/final` (`run1_cls` + `run1_seg_neg`, порог 0,976368, «проверьте» — способ A). `run3` — дообучение на внешних наборах (порог 0,989005, «проверьте» E0.6). `run4` — то же + выравнивание резкости и шума (R = 224; порог 0,981098, «проверьте» E0.9). Правило замены (П2 / П2ф) не выполнено ни у `run3`, ни у `run4`; отчет его не пересматривает. По экзаменам — только сводные числа; первый экзамен для `run4` открыт один раз (дата и версия записаны в журнале проекта). Интервалы — бутстреп по пациентам (2000 повторов, seed 42); разницы — парные (одни и те же срезы). `python -m src.compare_candidates`.
