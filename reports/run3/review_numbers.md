# Пояснения к сравнению версий: дополнительные разбивки

Только сводные числа из сохраненных предсказаний; модели не запускались, ничего не подбиралось. Посчитано после просмотра результатов экзаменов, поэтому это пояснения к сделанным замерам, а не новые проверки. Интервалы — бутстреп по пациентам (2000 повторов, seed 42), для долей пациентов и малых счетов — интервал Уилсона. `python -m src.review_numbers`.

## 1. Из чего состоят экзамены

- Оба экзамена вместе: 2883 срезов T1 с контрастом без опухоли у 292 пациентов.
- Это не здоровые люди: рассеянный склероз (Любляна) — 300 срезов, из них с очагом склероза 250; шванномы (Лондон) — 2583 срезов (90%), срезы взяты не ближе 10 мм от опухоли.
- Независимых центров два, но 90% срезов — из одного (Лондон); второй экзамен — только он.

## 2. Ложные тревоги: по срезам, по копиям и по пациентам

| версия | копия 42 (основная) | копии 42 / 43 / 44 | среднее трех копий | пациентов хотя бы с одной ложной тревогой |
|---|---|---|---|---|
| `models/final` (полуфинал) | 753 из 2883 (26.1%) | 26.1% / 27.6% / 22.2% | 25.3% | 264 из 292 (90.4%) [86.5%; 93.3%] |
| `run3` (финал) | 617 из 2883 (21.4%) | 21.4% / 22.7% / 23.0% | 22.3% | 255 из 292 (87.3%) [83.0%; 90.7%] |
| `run4` | 704 из 2883 (24.4%) | 24.4% / 26.4% / 17.2% | 22.7% | 268 из 292 (91.8%) [88.1%; 94.4%] |

Разница «вторая − первая версия», парный бутстреп по пациентам:

| пара | по копии 42 | по среднему трех копий |
|---|---|---|
| `run3` − `final` | -4.7 п.п. [-6.9; -2.7] | -3.0 п.п. [-4.8; -1.2] |
| `run4` − `final` | -1.7 п.п. [-3.8; +0.4] | -2.6 п.п. [-4.4; -0.8] |
| `run4` − `run3` | +3.0 п.п. [+1.6; +4.5] | +0.3 п.п. [-0.6; +1.3] |

Девять пар «копия `final` × копия `run3`»: от -6.2 до +0.7 п.п. Интервал по пациентам не учитывает случайность обучения: разница между версиями сопоставима с разбросом между копиями одной версии. Преимущество `run3` над `run4` по копии 42 (+3,0 п.п.) — удача одной копии; по среднему копий разницы нет.

Кто дал ложную тревогу у `run3`: модель контура нашла область на 496 из 617 срезов, на остальных 121 сработал только порог модели типа.

## 3. Ложные тревоги зависят от уровня среза (шванномы, оба экзамена)

Шваннома лежит у основания черепа, поэтому расстояние среза от опухоли — это и высота среза: рядом — основание черепа, дальше 60 мм — верх головы. Разбивка сделана после просмотра результатов.

| расстояние от опухоли | срезов | `models/final` (полуфинал) | `run3` (финал) | `run4` |
|---|---|---|---|---|
| 10–20 мм | 745 | 32.5% | 34.6% | 40.3% |
| 20–30 мм | 501 | 30.9% | 26.9% | 32.5% |
| 30–40 мм | 363 | 21.8% | 28.4% | 27.3% |
| 40–60 мм | 563 | 24.0% | 11.9% | 11.9% |
| дальше 60 мм | 411 | 19.2% | 2.2% | 2.7% |

Почему так может быть: в обучении у внешних наборов (UPENN-GBM, BraTS-MEN-RT) аксиальные срезы ниже 42% высоты головы отсекались — там стертое лицо (P11-1, `src/build_external_slices.py`, `--ax-min-frac`); на экзаменах этого ограничения нет. Аксиальных срезов без опухоли в обучении — 464, все выше этой границы. Два объяснения — «незнакомая больница» и «уровень среза, которого не было в обучении» — этой разбивкой не разделены; второе она подкрепляет: у `run3` у верха головы ложных тревог почти нет.

Пропуски на тесте полуфинала по типам: `models/final` — {'meningioma': 2, 'pituitary': 2, 'glioma': 1}, `run3` — {'glioma': 9, 'meningioma': 3, 'pituitary': 3}.

Условие П2 «пропусков на нашем val не больше чем на 1 п.п. больше» выполняется по построению: порог подбирается на том же val с требованием найти не меньше 98,5% опухолей (не меньше 462 из 469), а у `models/final` 466 — потеря не может превысить 0,85 п.п. Там, где порог не подбирался, `run3` теряет больше.
